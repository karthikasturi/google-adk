# Day 11 — Real-time voice TravelBot (DEFAULT: OpenRouter STT/TTS backend)
#
# This default backend uses your OpenRouter API key for STT *and* TTS — no
# Hugging Face download, no local ML models. Good for networks where
# huggingface.co is blocked.
#
# Install:  pip install -r requirements.txt
# Run:      python pipeline.py            (live mic loop, --backend openrouter)
#           python selftest.py            (mic-less latency benchmark)
#
# System audio libs (Debian/Ubuntu):  sudo apt-get install -y libportaudio2 ffmpeg
#
# For the fully-local faster-whisper + Piper backend instead, also install
# requirements-local.txt  (needs huggingface.co reachable to fetch the models).
